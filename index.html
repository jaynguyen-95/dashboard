Quản lý Jackpot

Nhập tay hoặc import dữ liệu từ hệ thống

Dán phản hồi JSON từ API hệ thống (hoặc file CSV/JSON xuất ra). App tự nhận các trường thời gian, số tiền, tên giải, nhóm, máy. Giải Machine lấy tên máy làm tên giải. Dòng nào đã import (cùng id, hoặc cùng thời gian + số tiền + máy) sẽ không bị nhân đôi.

Hoặc chọn file:

Định dạng được hỗ trợ

JSON: [ {...}, ... ]  hoặc  { "data": [ ... ] }
CSV : time,amount,jackpot,group,machine
      09/10/2026 14:32,12500,Vegas Weekly,Mystery,Slot A-112

Thời gian : time | timestamp | datetime | hit_time | won_at | created_at
            (ISO, epoch giây/ms, dd/mm/yyyy hh:mm, hoặc date + time)
Số tiền   : amount | value | win_amount | jackpot_amount | payout | prize
Tên giải  : jackpot | name | prize_name | level
Nhóm      : group | category | type  (Mystery | Hot Seat | Machine)
            bỏ trống: tự nhận theo tên giải, còn lại là Machine
Máy       : machine | machine_name | game | table
Số máy    : mc | machine_no | machine_number | machine_id | asset_no
Số liệu sàn (ở cấp ngoài cùng của JSON):
  active_players
  machines_available: { slot, roulette, baccarat }
  hot_jackpots: [ { name, group, amount, must_hit_by, rate }, ... ]
